# Code of Conduct

This project follows the Contributor Covenant (short version):

- Be respectful and inclusive.
- Assume positive intent, be kind when giving feedback.
- No harassment, discrimination, or personal attacks.

If you witness or experience unacceptable behavior, please open an issue or contact the maintainer.

For the full standard text, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
